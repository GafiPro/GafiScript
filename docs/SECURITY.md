# Security

Active layers:
- static source validation;
- source size limits;
- blocked host APIs;
- no annotation processing;
- generated bytecode inspection;
- restricted classloader;
- task/listener/command/GUI lifecycle cleanup;
- administrative permissions.

SAFE/TRUSTED/EXPERIMENTAL are trust levels, not formal JVM isolation guarantees.

Unknown or untrusted scripts should not be treated as safe code to run inside the Minecraft JVM.
